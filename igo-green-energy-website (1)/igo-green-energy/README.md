# iGo Green Energy — React Website Prototype

A premium renewable-energy website prototype built from the supplied iGo Green Energy questionnaire.

## Run

```bash
npm install
npm run dev
```

Open the Vite URL shown in the terminal.

## Build

```bash
npm run build
```

## Notes
- Frontend-only prototype.
- No Firebase/backend is included or modified.
- Replace CSS-generated visuals with approved production photography/video when the client supplies final assets.
- The project intentionally avoids invented project statistics, client logos, certifications and completed-project claims.
